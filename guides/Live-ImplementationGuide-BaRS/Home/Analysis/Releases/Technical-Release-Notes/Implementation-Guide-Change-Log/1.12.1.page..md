### 1.12.1

## Implementation Guide Changes

| Change                                | Description                                                                                             |
|---------------------------------------|---------------------------------------------------------------------------------------------------------|
| Assurance guidance | Removed the fixed “two to four weeks” assurance timeframe and clarified the factors that affect assurance timescales. | Non-breaking | Suppliers should not plan against a fixed assurance completion period. |
| Application 5 medication and allergy guidance | Clarified the medication and allergy requirements by replacing references to “novel” information with explicit wording about medication administered or prescribed, and new allergies established, during the latest assessment. | Non-breaking | Suppliers implementing Application 5 should review the clarified requirements. |
| Application 5 MedicationStatement guidance | Clarified that MedicationStatement is used to carry new medication prescribed during the encounter and SHOULD NOT be used to carry medication history obtained from external sources. | Non-breaking | Suppliers implementing Application 5 should review the clarified resource usage. |
| Get Referral HTTP 503 test guidance | Corrected the Sentinel Element reference published for the Get Referral HTTP 503 test. | Correction | Suppliers using this test guidance should use the corrected ServiceRequest reference. |
| Change-log presentation | Updated the Core and Application change logs to distinguish Change Type from supplier Impact. | Non-breaking | Information only. |
| External links | Updated external links across the Implementation Guide. | Correction | Information only. |
| NHS England logo | Updated the Implementation Guide to use its own NHS England logo asset instead of the legacy external media repository. | Correction | No supplier development required. |
| Release information | Updated the landing-page Guide, Package and Core version information for release 1.12.1. | Non-breaking | Information only. |
